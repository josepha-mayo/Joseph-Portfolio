# Counterstep Relay

An isolated, MIT-licensed project branch for an actual MCP tutoring workflow and an explicitly simulated Alexa+ host. This is not the portfolio's production branch. Do not merge it into master.

The first release workflow expands a SHA-256-verified snapshot of the new project files, retrieves the previously published Counterstep core and model using a fixed artifact hash, and runs real domain, SDK, HTTP-client and browser checks before recording a demonstration.

No accepted hackathon submission, live Alexa integration, measured learner outcomes or prize are claimed. Registration is pending one factual answer about the entrant's Amazon Developer account history. Source and actual test evidence will be preserved on this branch.

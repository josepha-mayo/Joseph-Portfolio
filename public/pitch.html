PROBLEM

One event. Two different commitments.

A node can report an event that is later orphaned. An external action can already be complete. Rolling back an index is not rolling back a delivery.

SOLUTION

Execute a fork. Rehearse your response.

Compile and deploy a Solidity fixture on a local EVM. Mine competing histories. Replay node-reported heads, choose a confirmation policy and simulate delivery acknowledgments.

CONTRIBUTION

Make the irreversible boundary visible.

Separate canonical observations from acknowledged work. Deduplicate repeated events. Latch an incident after evidence is lost. Save and replay the same decisions. This combines established techniques; it does not invent reorg handling.

Trace provenance and limits
The fixture is generated by compiling and deploying DemoOrders.sol, submitting transactions, mining, then reverting a local snapshot and producing a competing branch. The website replays that recording; it does not connect to Ethereum or simulate live consensus. Run npm run evm to generate a fresh trace locally.
Ganache is archived and used only as an isolated development fixture. Forkline does not verify headers cryptographically, prove RPC completeness, choose Ethereum’s canonical chain, or guarantee exactly-once delivery to external services. The core trusts its supplied observation graph. No external webhooks, wallets, custody or real tokens.

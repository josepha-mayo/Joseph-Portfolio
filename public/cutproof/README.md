# CutProof: Context-First Clip Studio

This directory is a separate, AI-assisted hackathon project built on September 6, 2026. It is temporarily hosted through an isolated Netlify Deploy Preview. The portfolio's production branch and production website are not modified.

CutProof imports timestamped SRT, VTT, or JSON captions, ranks contiguous source ranges, exposes potentially missing context for editorial review, and exports captions, source references, saved projects, and actual locally rendered clips.

The application code and reproduction instructions are being published to this directory. This branch is a publication workspace, not evidence of a completed deployment, accepted hackathon entry, independent audit, or prize.

Do not merge this preview branch automatically. No account credentials belong in this directory or its history.

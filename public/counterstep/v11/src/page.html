    What the AI does, and where it stops

    The 62 → 24 → 5 neural network is trained on 3,200 generated erroneous step pairs. It ranks distribution, balance, division, bracket signs and arithmetic. It does not generate proofs or infer why a real learner made an error.

    The development numeric holdout shares the five templates: 93.7% top-class accuracy on 600 cases. A side-order normalization fixes a severe earlier failure. These are synthetic development results, not student validation. A later fresh coefficient split reached 487/600 top-class matches; the model issued 475 suggestions, all matching those synthetic injected-edit labels. This narrow result is not a guarantee for other equation forms. Full failures are in the source package.

    All real-number linear solution-set comparisons use a separate BigInt rational parser. A malformed or unsupported line stops the check. Equivalent equations can still be pointless steps or use bad explanations; this tool cannot validate unwritten reasoning.

    No account, API key, large-model download, external request or browser storage is required. The downloadable Python training script and JavaScript inference checks document the learned weights.

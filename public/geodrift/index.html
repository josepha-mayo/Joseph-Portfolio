A review tool, not an identity oracle
The gaps matter as much as the changes.
A missing range is not permission to allow access. GeoDrift keeps “uncovered” separate from a country classification and uses exact 128-bit arithmetic at IPv6 boundaries. Country labels reflect supplied data, not verified residence, citizenship or identity.
Changes to input clear the result and disable exports. “No decision change” means only that these snapshots and these policies produced the same decisions, not that either one is correct.
